
1. Распакуй архив

2. Открой папку в VS Code

3. В терминале VS Code:

npm install

4. Потом:

npm run dev

5. Закинь свои фото сюда:
src/assets/images/

Названия:
photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg
photo5.jpg

6. Музыку сюда:
src/assets/music/

Названия:
track1.mp3
track2.mp3
track3.mp3
track4.mp3
track5.mp3
